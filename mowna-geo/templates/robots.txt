# robots.txt 模板 · 魔女GEO 关卡 1 交付物
# ---------------------------------------------------------------
# 使用说明：
#   1. 把 example.com 换成你的域名
#   2. 检索型爬虫段落：保持 Allow，不要动
#   3. 训练型爬虫段落：二选一，取消对应注释
#   4. 部署后用 python scripts/geo_scan.py 你的域名 复核
#   5. 一周内查服务器日志，确认 bot 真的进来了
# ---------------------------------------------------------------
# 核心原理：训练型爬虫与检索型爬虫是分开的。
#   屏蔽检索型 = 直接放弃被 AI 实时引用的机会
#   只屏蔽训练型 = 仍享有实时引用机会
# 已证实的代价：Rutgers / Wharton 研究显示，全面屏蔽 AI 爬虫的发布方
#   流量下降超 23%，且并未换来引用下降——因为屏蔽同时打中了检索型 bot。
# ---------------------------------------------------------------
