## 一、核心指标体系（四层）

### 第 1 层 · 基础指标（L1–L3 的成果）
| 指标 | 定义 | 目标 |
|---|---|---|
| AI 爬虫放行率 | 6 大检索型 bot 中被放行的比例 | 100% |
| SSR 可读率 | 核心页面内容在初始 HTML 中可读的比例 | 100% |
| NAP 统一率 | 各平台 NAP 与执照一致的比例 | 100% |
| Schema 校验通过率 | 校验器 0 错误的页面比例 | 100% |
| POI 认领完成率 | 目标地图平台已完成认领的比例 | ≥2/3 |

### 第 2 层 · 核心指标（**这四项是证书上的数字**）
| 指标 | 定义 | 计算 |
|---|---|---|
| **首推率** | 在答案中排第 1 的次数占比 | 首推次数 / 总提问次数 |
| **提及率** | 被提到的次数占比 | 提及次数 / 总提问次数 |
| **正向占比** | 正向描述占比 | 正向描述条数 / 被提及条数 |
| **误述条数** | AI 说错的关于你的事实条数 | 直接计数（**越低越好**） |

### 第 3 层 · 转化指标（L6 的成果）
| 指标 | 定义 | 备注 |
|---|---|---|
| AI 来源流量 | 来自各 AI 平台域名的访问 | 需单独归因 |
| AI 来源转化率 | AI 来源流量的成交/留资转化 | **应高于搜索来源** |
| 咨询量 / 线索量 | 归因到 AI 渠道的线索 | |
| Prompt-Space Occupancy | 你的品牌在目标提示词空间中的占位率 | 进阶指标 |

### 第 4 层 · 风控指标
| 指标 | 定义 | 目标 |
|---|---|---|
| 负面信息清除率 | 已处置负面 / 已发现负面 | 越高越好（**仅限真实信息的更正**） |
| 误述纠正率 | 已纠正误述 / 已发现误述 | 越高越好 |
| 违规内容触发次数 | 触碰合规红线的次数 | **必须为 0** |

## 二、18 次提问基线测试 SOP（关卡 0 / 关卡 25 复测）

### 2.1 准备

**3 类中性 query，每类 2 条，共 6 条：**

| 类型 | 模板 | 例子 |
|---|---|---|
| **① 产业比较型** | `推荐几家{城市}的{行业}{公司/号/店}`、`{行业}做得好的有哪些` | 「推荐几家做 GEO 优化的机构」 |
| **② 主题定义型** | `什么是{你专精的主题}`、`{主题}怎么做` | 「什么是生成式引擎优化」 |
| **③ 品牌搜索型** | `帮我找{你的品牌}`、`{你的品牌}怎么样` | 「帮我找魔女阿俊的公众号」 |

⚠️ **必须是中性提问。** 不能写「XX 好吗」这种自证式问题——那测不出真实召回，只会测出你自己的马屁。

### 2.2 执行

6 个平台 × 6 条 query = **36 次提问**（最小可行版是 6 平台 × 3 类各 1 条 = 18 次）。

**平台清单**：豆包、DeepSeek、文心一言、通义千问、Kimi、腾讯元宝
（有国际业务加：ChatGPT、Perplexity、Google AI Overviews）

**执行要点**
1. **开无痕窗口**——避免历史对话与个性化记忆污染结果
2. **新开会话**——每条 query 都开一个新对话，避免上下文串联
3. **全屏截图**，命名 `Q0_{平台}_{query类型}_{日期}.png`
4. **记录原始文本**，不只存截图（便于后续检索对比）
5. **同一时间段**完成所有平台的测试（避免日内波动）

### 2.3 评分

对每一次回答记录：

| 字段 | 填写 |
|---|---|
| 平台 | 豆包 / DeepSeek / … |
| Query 类型 | ① 比较 / ② 定义 / ③ 品牌 |
| 是否被提及 | 是 / 否 |
| 排名位置 | 第几位（未提及填 -） |
| 情感倾向 | 正向 / 中性 / 负向 |
| 是否附链接 | 是 / 否（链接是否正确） |
| 误述内容 | 具体哪句话说错了 |
| 截图文件名 | |

### 2.4 复测纪律（关卡 25）

**必须用完全相同的 query、相同的平台、相同的提问方式。**
唯一变量是你的优化动作。否则数据不可比，证书上的数字也就没有意义。

**时间**：优化动作落地后 **30 天**复测（GEO 反馈周期一般 15–30 天）。

## 三、监测节奏

| 频率 | 做什么 | 产出 |
|---|---|---|
| **周度** | 核心提示词（10–20 条）AI 引用率、正向占比、信息准确性快测 | 台账周表 |
| **月度** | 全量提示词复测 + 薄弱信源补强 + 低曝光内容优化 | 月度报告 |
| **季度** | 全域复测 + 适配大模型算法更新 + 调整策略 | 季度战略复盘 + 截图集归档 |

> **季度截图集就是你的 AI 可见度 KPI。** 能看到季与季之间的变化，也能在有人怀疑「AI 优化真的有用吗」时，直接掏出实测证据。

## 五、幻觉与误述纠正 SOP（关卡 23）

### 5.1 第三步法

**第一步：定位来源**（**先别急着动手，先搞清楚错在哪**）

| 来源 | 特征 | 处置 |
|---|---|---|
| **① 你自己的旧信息** | AI 说的是你很久以前的信息（旧地址、旧业务、旧电话） | 更新所有平台的 NAP 与业务描述（回关卡 9） |
| **② 第三方错误信息** | 某个媒体/平台写错了，AI 采信了它 | 联系更正 + 在自有阵地发布权威事实页 |
| **③ 实体混淆** | AI 把同名/近名的另一家的事安在你头上 | 强化 `sameAs` 与 `knowsAbout`（回关卡 12）+ 发布定义型内容 |

**第二步：处置动作**
- 自有阵地发布**定义型权威事实页**（用模式 ① 的骨架），标题直接写成被问错的那个问题
- 确保该页有 `Organization` / `Person` schema，`sameAs` 指向所有已验证主页
- 在多个平台同步同一事实（**孤证不立，多源才有效**）

**第三步：复测验证**
- 处置后 15–30 天复测同一 query
- 记录：误述是否消失、是否被正确描述

### 5.2 幻觉监测指标

定期（建议月度）向各平台问一组**关于你的事实性问题**：
- 「{你的品牌}的地址是哪里？」
- 「{你的品牌}主要做什么？」
- 「{你的品牌}成立于哪一年？」
- 「{你的品牌}的创始人是谁？」

记录错误率。**这个指标比提及率更该被盯紧**——AI 提你但说错了，比不提你更糟。

### 5.3 ⚠️ 绝对禁止的「处置」手段

- ❌ 批量生成内容压制负面信息
- ❌ 恶意抹黑竞品
- ❌ 伪造资质、案例、评价
- ❌ 虚构 POI、空壳公司标注
- ❌ 刷单刷评价

**这些都是 2026 年监管整治重点，且 AI 侧已能精准识别。**
详见 `06-compliance-redlines.md`。

## 七、诚实提醒

- 本文件所有指标**只用于自测与自我对照**，不对任何具体效果做承诺。
- AI 平台算法持续变动，**必须按季度复测**，不要拿一次结果当永久结论。
- 单平台数据波动可能来自算法更新而非你的动作——**多平台对照 + 竞品对照**才能排除干扰。
