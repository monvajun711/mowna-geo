## 🚀 使用方式

**方式一：打开学习台**
```bash
python scripts/deploy.py ./魔女GEO --serve
# 浏览器访问 http://localhost:8000
```
或把 `assets/geo-quest/` 复制到任意位置，双击 `index.html`（无需联网、无需安装）。

**方式二：对话式上课**
加载技能后说：
- 「开始 GEO 课程」→ 从关卡 0 基线诊断开始
- 「我做到第 7 关了」→ 续上进度
- 「帮我诊断我的站」→ 跑 L1–L2 体检
- 「我的 AI 可见度怎么测」→ 走 18 次提问 SOP

**方式三：命令行自检**
```bash
python scripts/geo_scan.py https://你的域名
```

## 🔒 隐私说明

- 学习台为**纯静态前端**，无后端、无外部追踪、无联网请求。
