# 赛博手搓盆景：Skill 内游戏规则

这是可在对话中运行的轻量规则，也是在线版的领域模型。玩家掌握所有不可逆选择。

## 核心循环

选坯 → 四观定势 → 定正面与流派 → 养根蓄势 → 截干/取枝 → 蟠扎/牵引 → 季节推进 → 细化 → 配盆铺面 → 上展评分 → 收藏与复盘。

一局推荐 8–12 回合，每回合代表关键作业窗口而非固定天数。不得让玩家连续执行多个高风险动作而无恢复季。

## 初始选择

1. 地域气候：寒温、温带、亚热带、热带；露台、庭院或室内窗边。
2. 树种：新手默认榔榆；进阶可选真柏、黑松、罗汉松、雀梅、枫、杜鹃等。
3. 素材：苗木、圃地坯、老桩、半成品；决定根盘、干径、伤口与预算。
4. 目标：扬派云片、岭南大树型、岭南素仁格、苏派、通派两弯半、自然式等。

## 动作与代价

| 动作 | 主要收益 | 即时代价/风险 | 前置 |
|---|---|---|---|
| 观察与补拍 | 提高信息与正面判断 | 低 | 无 |
| 调光/通风 | 活力、节间控制 | 环境骤变可应激 | 树种与气候匹配 |
| 浇水 | 水分恢复 | 过量伤根 | 看介质而非日程 |
| 轻肥 | 蓄势 | 弱根或休眠期肥害 | 有主动生长 |
| 蓄养牺牲枝 | 干径、收尖、愈合 | 局部失衡、留疤 | 规划出口 |
| 截干 | 收尖与动势重建 | 高压力、大伤口 | 强树、合适物候、接续芽 |
| 结构剪 | 主枝秩序 | 失枝与回枯 | 先定正面 |
| 细剪/摘芽 | 节间与细枝 | 过量削弱 | 旺树、有光 |
| 蟠扎/牵引 | 枝位与动势 | 勒痕、折枝 | 枝条柔韧、复查 |
| 翻盆修根 | 根盘与介质更新 | 最高根压 | 物候窗口，不与重剪同回合 |
| 换观赏盆 | 盆树相宜 | 生长空间下降 | 根系成熟 |
| 摘叶 | 细枝和叶片缩小 | 高能耗 | 仅适宜树种的强树 |
| 枯木作 | 年龄与险峻感 | 活脉损伤 | 适宜针叶、明确活脉 |

## 季节结算

结算顺序：环境 → 水分 → 根系 → 能量 → 芽枝生长 → 伤口愈合 → 铁丝勒痕 → 病虫事件 → 美学变化。随机事件必须可解释，并给玩家一次预防或补救选择。

## 教学与公平

- 不设置唯一标准答案；每个任务至少支持两条高分流派路线。
- 预览显示方向与风险，不显示精确最优值；结算解释因果。
- 观察、相机和陈设可撤销；剪枝、截干、修根不可撤销，沙盒模式可读档。
- 游戏内几何和生理分由状态模型直接计算；AI 只写审美解释与方案，防止分数漂移。

## 终局

玩家选择“上展”后冻结状态，按四观 85 + 流派 15 计分。输出时间线、最终图、雷达、五个证据点、两句匹配评语、下一年计划。健康闸门可压低当前展评分，但另显艺术潜力分。
